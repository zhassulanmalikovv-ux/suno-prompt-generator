# Suno AI Prompt Studio

Streamlit және Groq `openai/gpt-oss-20b` негізіндегі қосымша: өлең мәтінін немесе идеяны Suno AI үшін екі бөлек, көшіруге дайын нәтижеге айналдырады. Бұл ашық модель Groq-та орындалады; OpenAI API кілті қажет емес.

- **Style Prompt:** 900 символға дейінгі ағылшынша детальді сипаттама: жанр, аспаптардың рөлі, BPM, ырғақ, аранжировка, динамика, вокал тембрі, диапазон және микс. ИИ 600–850 символ аралығындағы мазмұнды промптқа ұмтылады.
- **Дауыс:** қоңыр дауысты қыз (contralto), soprano, mezzo-soprano, tenor, baritone, bass, қарлығыңқы дауыс, хор, дуэт және сыбыр. Қосымша тембр мен орындау мәнерін өзіңіз сипаттай аласыз.
- **Structure Lyrics:** `[Verse 1]`, `[Chorus]`, `[Bridge]`, `[Outro]` және қажет болса `[Instrumental Drop]` тегтері бар өлең.
- **Өлең тілі:** бастапқы тілді сақтау немесе таңдалған тілге мағынасын сақтап аудару; өз тілін және жазуын көрсету мүмкіндігі бар.
- Әр нәтиже `st.code()` блогында стандартты Copy батырмасымен беріледі.
- Premium dark интерфейс: градиентті тақырып, PRO / AI Powered бейджі, glassmorphism карточкалар, неон батырма және мобильді экранға бейімделетін екі баған.
- 10 қазақша жанр: той, мұңды, лирика, халық әні, терме, дәстүрлі ән, эстрада, Q-Pop, рэп және этно-фьюжн; халықаралық жанрлар да сақталған.
- Телефонда бір баған, ықшам мәтін өрісі, 16 px қаріп, 44–48 px touch нысаналары және жеңілдетілген карточка эффектілері.

## Музыкалық конструктор

- **560 жанр / ішкі жанр, 29 санат:** қазақша және түркі музыкасы, Trap, Hip-Hop, Drill / Phonk, Pop, R&B, Rock, Metal, House, Techno, Trance, Jazz, Folk, Classical және басқа бағыттар. Санат өзгергенде ішкі жанр мен аймақтық стиль бірден жаңарады.
- **Аймақтық стиль:** Trap / Rap үшін California, Los Angeles, Atlanta, Memphis, Houston, Detroit; басқа жанрларға Chicago, Berlin, Nashville, Vienna, Seoul және тиісті музыкалық сипаттар.
- **Бөлек дауыс түрі, диапазон және бірнеше тембр таңдауы:** негізгі дауыс түрлері және 12 вокал регистрі × 12 тембр комбинациясы, сонымен бірге instrumental. Диапазон, қоңыр/барқыт/ауадай/қарлығыңқы тембр, орындау тәсілі мен бэк-вокалды біріктіруге болады.
- **Тіл:** қазақ, өзбек, қырғыз, түрік, әзербайжан, түрікмен, ұйғыр, татар, башқұрт және басқа түркі тілдері, тілдік және тарихи нұсқалар. Басқа тіл / диалект атауын еркін енгізуге болады. Жазу жүйесі бөлек таңдалады. Сирек және тарихи тілдердегі мәтіннің дұрыстығын тілді білетін адам тексергені жөн.
- **Аранжировка:** 71 аспап, үш қосымша жанрға дейін fusion, қолмен 40–240 BPM, өлшем, groove, ән құрылымы және динамика.
- **Студия:** autotune, pitch correction, vocoder, reverb, echo / delay, compression, EQ, saturation, stereo және вокалдың микстегі орны.
- **Еркін эксперимент:** жеке музыкалық бағыт пен қоспау керек элементтерді енгізуге болады. Auto опциясы параметрді жанрға сай таңдауды ИИ-ға қалдырады.

Таңдаулар өзгергенде API шақырылмайды: генерация тек **Generate Suno Prompt** батырмасымен орындалады. Алдыңғы нәтиже басқа баптауларға тиесілі болса, интерфейс оны көрсетеді. Барлық таңдаулар 900 символ ішіндегі промптқа жинақталады; параметрлер көп болса, ИИ оларды ықшамдайды.

Каталог `catalog.py` файлында, интерфейс пен генерация `app.py` ішінде. Жанр/тембр нұсқалары жеке дыбыс модельдері емес, генераторға берілетін музыкалық сипаттамалар.

## Тексеру

```bash
python -m unittest discover -s tests -v
```

Тесттер каталог көлемін, жанрға байланысты таңдау тізімін, 900 символ шегін, тіл/вокал/эффектілердің Groq сұрауына берілуін және қате өңдеуін тексереді. Нақты API шақырулары жасалмайды.

## Жергілікті іске қосу

Python 3.11 немесе 3.12 ұсынылады.

```bash
git clone https://github.com/zhassulanmalikovv-ux/suno-prompt-generator.git
cd suno-prompt-generator
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

`.streamlit/secrets.toml` файлын жасап, өз кілтіңізді қойыңыз:

```toml
GROQ_API_KEY = "your-groq-api-key"
```

```bash
streamlit run app.py
```

Кілтті [Groq Console](https://console.groq.com/keys) арқылы алыңыз. Ол тек `st.secrets["GROQ_API_KEY"]` арқылы оқылады. `.env` қолданылмайды; `python-dotenv` тәуелділігі бастапқы сұранысқа сай енгізілген. Құпия файлдар `.gitignore` ішінде.

## Streamlit Community Cloud-қа орналастыру

1. [Streamlit Community Cloud](https://share.streamlit.io/) жүйесіне GitHub аккаунтыңызбен кіріңіз.
2. **Create app** арқылы `zhassulanmalikovv-ux/suno-prompt-generator` репозиторийін, `main` тармағын және `app.py` файлын таңдаңыз.
3. **Advanced settings → Secrets** ішіне жоғарыдағы TOML форматымен нақты `GROQ_API_KEY` енгізіңіз. Python нұсқасын 3.11 немесе 3.12 таңдаңыз.
4. **Deploy** басыңыз. Тәуелділіктер `requirements.txt` арқылы орнатылады.

Нұсқаулық: [Streamlit deployment docs](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app).

## Қолдану

Өлең не идея енгізіп, жанрды, көңіл-күйді, дауыс түрін және аударма опциясын таңдаңыз. **Generate Suno Prompt** басып, екі нәтижені Suno-ның **Style of Music** және **Lyrics** өрістеріне көшіріңіз. Аударма өшірілсе, өлеңнің бастапқы тілі сақталады; идеядан сол тілде жаңа өлең жазылады.

Нәтиже [Groq JSON Object Mode](https://console.groq.com/docs/structured-outputs#json-object-mode) арқылы алынады. Қосымша екі мәтіндік өрісті, 900 символ шегін және өлең тегтерін тексереді, сәйкес болмаса бір рет түзетуді сұрайды. API қатесі немесе толық емес нәтиже пайдаланушыға түсінікті хабарлама береді.

Генерация Groq аккаунтының API лимиттерін пайдаланады. Пайдаланушы енгізген мәтін Groq-қа жіберіледі. Нәтижелер тек ағымдағы Streamlit сессиясында сақталады.

## OpenAI-дан Groq-қа ауысу

Streamlit Cloud-та Secrets ішіндегі кілт атауын `GROQ_API_KEY` деп ауыстырып, нақты Groq кілтін енгізіңіз. `requirements.txt` енді `groq` SDK орнатады. Ескі `OPENAI_API_KEY` бұл қосымшаға қажет емес.

### Қазақша интерфейс және дауыс таңдауы

Интерфейс атаулары мен каталог таңдаулары қазақша көрсетіледі; API-ға бастапқы музыкалық мәндер беріледі. Дауыс түрі мен диапазон қатар орналасады: еркекке бас/баритон/тенор/контртенор, әйелге контральто/альт/меццо-сопрано/сопрано. Тембрден төрт сипатқа дейін бірге таңдауға болады. Дауыссыз режим тембрді қолданбайды. Suno үшін стильдік нәтиже ағылшынша, құрылым тегтері Suno форматына сай сақталады.

### Орындаушы пресеттері

Қазақша іздеу мен бағыт бойынша сүзгісі бар 100-ден астам орындаушы/топ пресеті. Таңдау баптауларды автоматты толтырады, API шақырмайды және енгізілген өлең мен тілді сақтайды. Музыкалық бағыттар — редакциялық бастапқы нүктелер: бірнеше орындаушы ортақ профильді қолданады, кейбіріне жеке түзетулер берілген. Бұл нақты дауыс көшірмесі немесе әнді қайталау кепілдігі емес. API сұрауына кітапханадағы орындаушы аты жіберілмейді; тек аспап, регистр, тембр, ырғақ және дыбыс өңдеу сипаттары беріледі. Пресеттен кейін барлық параметрлер еркін өзгертіледі.
